AI Monitor Browser Extension Install

The AI Monitor Browser Adapter reports supported AI website task state to the AI Monitor desktop app running locally on your Mac.

The browser adapter is being prepared for Chrome Web Store or managed-extension distribution. You can install and use the macOS desktop app now with IDE and terminal integrations. This page will be updated with the browser install button when the browser adapter is approved.

After installing

  1. Open AI Monitor on your Mac.
  2. Open Settings and click Copy API token.
  3. Open the browser extension popup, paste the token, save, and click Test.
